# PSOS

**PSOS** is a serious systems experimentation project, not a toy OS.  
It is built around intentional tinkering: testing ideas, breaking assumptions, and learning through low-level implementation.

## What this repository is for

- Exploring operating-system concepts in code
- Running focused experiments on core subsystems
- Documenting decisions, trade-offs, and failures

## Current status

Early-stage and evolving. Interfaces and behavior may change frequently.

## Philosophy

Build small pieces, test aggressively, keep what proves useful.

## Contributions

Contributions are welcome, especially focused and well-explained changes.

If you'd like to contribute:

1. Open an issue to discuss the idea first (for non-trivial changes).
2. Keep pull requests small and scoped to one purpose.
3. Include clear reasoning in the PR description (what changed and why).
4. Update docs when behavior or interfaces change.

Constructive discussion, experiments, and even failed attempts with good write-ups are valuable here.
